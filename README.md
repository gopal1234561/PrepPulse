# PrepPulse

A focused GATE 2027 daily study assistant.

## Current build
- Mobile-first React/Vite dashboard
- GATE countdown
- Daily study tasks with local persistence
- Subject-wise preparation progress
- Morning, evening and night alert schedule
- Browser notification permission flow
- Email and notification settings UI
- No paid SMS dependency

## Run locally
```bash
npm install
npm run dev
```

## Roadmap
1. Connect Web Push/PWA notifications.
2. Add a small Node/Express notification scheduler.
3. Add free-tier email delivery.
4. Add daily plans, PYQ and mock-test tracking.
5. Deploy frontend/backend with environment variables.

PrepPulse is designed for a single focused GATE 2027 workflow first, with minimal unnecessary dashboard noise.
