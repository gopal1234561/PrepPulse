# PrepPulse\n\nA focused GATE 2027 daily study assistant with real browser push reminders.\n\n## Frontend\n- React + Vite\n- Mobile-first UI\n- Daily tasks and subject progress\n- GATE 2027 countdown\n- PWA manifest + service worker\n- Web Push subscription\n- Default reminders: **04:00, 17:30, 21:30 IST**\n- No paid SMS and no notification sound/alarm requirement\n\n## Notification backend\n\nThe `server/` folder contains an Express + Web Push scheduler. It stores browser push subscriptions and reminder times, checks every minute in **Asia/Kolkata**, and sends morning, evening and night push notifications.\n\n### Backend environment variables\n\n~~~\nVAPID_PUBLIC_KEY=...\nVAPID_PRIVATE_KEY=...\nVAPID_CONTACT=mailto:your-email@example.com\nTIMEZONE=Asia/Kolkata\nDATA_DIR=./data\n~~~\n\nGenerate a VAPID key pair once with the `web-push` package. Keep the private key only on the backend. The public key is returned by `/api/config`.\n\n### Deploy backend\n\nUse a Node service with root directory `server`, build command `npm install`, and start command `npm start`. Set the environment variables above. Then set the frontend Vercel environment variable `VITE_API_URL` to the deployed backend URL and redeploy the frontend.\n\n### Phone setup\n\n1. Open PrepPulse over HTTPS on Android Chrome.\n2. Tap **Enable mobile push**.\n3. Allow notifications.\n4. Keep the reminder times at **04:00 / 17:30 / 21:30** or change them in Settings.\n5. Optionally install PrepPulse to the home screen.\n\n### Important\n\nThe scheduler must stay running for exact scheduled delivery. If the backend host sleeps/stops the service, scheduled pushes cannot be sent while it is stopped. The current frontend and backend structure is ready; hosting configuration and VAPID keys still need to be supplied.\n\n## Run frontend locally\n\n~~~\nnpm install\nnpm run dev\n~~~\n\n## Run backend locally\n\n~~~\ncd server\nnpm install\nnpm start\n~~~\n
